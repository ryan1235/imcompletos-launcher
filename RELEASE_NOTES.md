## :wrench: DeathAwaits v1.0.1 — Correção do login Microsoft

### :bug: Correções
- :key: **Login com conta original (Microsoft) corrigido** — os erros aparecem agora em português, explicando o motivo real (conta sem Minecraft, sem perfil Xbox, sem internet etc.) em vez de uma mensagem quebrada
- :arrows_counterclockwise: A sessão Microsoft é **renovada automaticamente**; se expirar, o launcher abre o login de novo sozinho
- :lock: A janela de login agora abre por cima do launcher e começa sempre "limpa", sem sobras de outra conta
- :memo: Novo log de autenticação em `logs/auth.log` para ajudar a descobrir problemas

> [!NOTE]
> Para jogar com conta original é preciso ter o **Minecraft Java Edition** comprado na conta Microsoft. Sem ele, use a conta pirata (offline).
